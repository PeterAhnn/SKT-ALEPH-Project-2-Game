# 과제 2 검증 기록 — 2026-09-16

## 범위와 구분

Windows Chromium, gstack browse로 로컬 게임을 확인했다. 게임 규칙은 변경하지 않고 PC 레이아웃만 수정했다.
`qa/`의 브라우저 스크립트·JSON·화면 캡처는 검증 증거이다. 자동 입력과 경계값을 준비한 검사의 기록은 학생의 A/B 20회 플레이 기록으로 사용할 수 없다.
10분 실행은 127.0.0.1:8000, 저장·경계 검사는 127.0.0.1:8001에서 분리했다.

## 완료된 검사

- `npm test`: 11/11 통과. 포함된 600초 엔진 시뮬레이션은 별도 검사이다.
- 최초 1366×768에서 게임 바닥 y=823.83, 조작 버튼이 화면 아래로 밀림을 확인했다.
- PC 화면 높이에 따라 게임 폭을 제한하고 16:9 비율을 보존했다. 수정 후 1366×768의 조작바 하단 y=614.81, 1920×1080의 조작바 하단 y=927.81. 두 화면의 문서 폭은 각각 1366 / 1920으로 가로 넘침 없음.
- 10 keydown/keyup 쌍을 약 83ms 안에 전송: 입력 10, 반영 10, x 이동 30px. 이후 프레임에서 중복 반영 없음.
- 1.2초 정지 중 전체 엔진 직렬화 값 동일. 재개 후 시간 증가.
- 브라우저에 blur 이벤트를 전송하여 자동 정지·입력 해제·복귀 후 이동을 확인했다. 실제 OS 창 전환은 별도 수동 확인 권장.
- 정지 상태에서 1920×1080으로 변경한 뒤 전체 엔진 값 동일.
- 성공/실패 경계값을 준비한 브라우저 검사에서 재시작의 HP 100, 시간·점수 0, 레벨 1, 적·탄환·경험치·입력 0을 확인했다.
- 1단계 성공 → 2단계, 2단계 성공 → 3단계 이동 및 초기화 확인. 마지막 단계의 다음 버튼 숨김 확인.
- 강화 선택 중 정지/재개 시 선택 상태 유지, 강화 후 플레이 재개. 중도 종료 시 완료 기록 추가 없음.
- 빈 저장값은 기본값으로 시작. 잘못된 JSON은 복구 안내와 기본값으로 복구.
- 저장 후 새로고침에서 최고 점수·해금·설정·기록을 보존. 움직임 줄이기 설정 보존 확인.
- 성공 시 5×5 축하 입자 그리기 발생, 평상시·실패 시 없음. 움직임 줄이기를 켠 직후 추가 입자 그리기 0건.

## 재현

게임 서버를 실행한 뒤 gstack browse로 접속한다. `qa/attach.js`는 엔진 상태를 관찰하며 규칙을 바꾸지 않는다.
`qa/check-controls.js`는 입력·정지 검사, `qa/check-lifecycle.js`는 준비한 경계 상태 검사, `qa/soak.js`는 실제 600초 자동 조작이다.
검사 종료 후 QA 브라우저의 저장값을 비우고, 사람 플레이는 다른 브라우저/출처에서 시작한다. PC 이동 준비로 qa/의 PNG 화면 캡처 3개도 텍스트 재현 스크립트·측정 JSON과 함께 Git에 보관한다. 이는 기존 검사 증거의 보관이며 새 검사를 수행한 기록이 아니다.
