## 재현·통과 확인 4가지

어디로 가나요: 공개 결과물 URL에서 DEV SURVIVOR 게임을 엽니다.
무엇을 하나요(3단계 이내): 1) 생존 시작 2) WASD·방향키로 이동하고 레벨업 시 강화를 선택해 성공 또는 실패까지 진행 3) 종료 화면에서 다시 도전을 선택합니다.
무엇이 보이면 통과: 이동·자동 공격·체력·시간 표시가 작동하고, 30초 생존 시 성공하며 다음 스테이지가 해금됩니다. 체력 0이면 실패하고, 다시 도전하면 체력 100·남은 시간 30초·점수 0으로 초기화됩니다.
안 될 때: 생존 중 이동·시간이 멈추거나 다시 도전이 반응하지 않으면 오류입니다. 일시정지·강화 선택 중 멈춤은 정상이며 이어하기·강화 선택으로 재개합니다. 저장값이 손상되면 복구 안내와 함께 기본값으로 시작합니다.

## AI와 내 판단 3줄

AI에게 맡긴 일: 게임 코드·이미지 준비·저장 복구·검사 코드·배포 설정 구현.
내가 판단한 일: IT 소재 뱀서라이크, 세 금기어 스테이지, 개발자 외형, 순차 진행과 일시정지 메뉴, GitHub 공개 소스 방식.
AI 말을 안 들은 일: 독립 스테이지 선택·다운로드용 소스 페이지 대신 순차 해금과 공개 GitHub 저장소를 요청함.
