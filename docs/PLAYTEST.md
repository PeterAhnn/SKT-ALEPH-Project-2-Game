# 사용자 난이도 비교 — A 10회 / B 10회

게임: https://skt-aleph-project-2-game-peter-ahns-projects.vercel.app

같은 PC·브라우저·주소를 끝까지 사용한다. 로컬 QA의 자동 기록은 포함하지 않는다.

1. 1스테이지를 선택하고 **플레이 기록 → 다음 판 설정 A (0.8초)**를 선택한다. 창을 닫고 같은 스테이지를 성공/실패로 10회 끝낸다. 성공 시 ‘다음 스테이지’ 대신 ‘현재 스테이지 다시 도전’을 누른다.
2. **플레이 기록 → B (0.6초)**로 바꾸고 동일한 방식으로 10회 끝낸다. 가능한 한 같은 이동 방식·강화 선택 기준을 유지한다.
3. 플레이 기록에서 A/B가 각각 10/10인지 확인하고 **CSV 내려받기**를 누른다. 두 설정의 생존 시간·점수 중앙값과 생존 범위·실패 원인을 비교한다.

중도 종료한 판은 횟수에 포함되지 않는다. 기존 사람 플레이 기록이 있으면 먼저 CSV로 보관한다. 초기화가 필요할 때만 저장 초기화를 사용한다. 초기화는 해금과 최고 점수도 지운다.

플레이 중 실제 다른 창으로 옮겼다가 돌아온 뒤 ‘일시정지’인지 확인하고 ‘이어하기’로 정상 이동하는지도 한 번 확인한다.

최종 선택 시 다음을 본인 판단으로 적는다.

- A와 B 중 어느 쪽이 적절했는가?
- 중앙값·범위 또는 반복 실패 원인 중 어떤 기록이 그 판단을 뒷받침하는가?
- 화면 크기, 조작감, 반복 플레이에서 불편했던 점이 있는가?

아직 실제 20회 기록과 최종 선택은 완료되지 않았다. AI가 임의로 대신 작성하지 않는다.
